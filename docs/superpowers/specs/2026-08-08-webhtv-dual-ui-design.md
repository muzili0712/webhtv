# WebHTV 双端 UI 重设计规格

## 1. 目标与边界

为 WebHTV 提供一套可一比一还原的双端 UI 设计，不改动现有业务能力与数据逻辑，只重组信息架构、视觉层级和交互路径。

已确认的方向：

- 视觉方向：A「电影感聚焦」——深色沉浸、海报与内容信息优先，石灰黄作为播放与焦点色。
- 壁纸：可随时更换，作用于整个应用。
- 主题：默认深色，同时提供“跟随系统”的浅色适配；壁纸不是唯一主题来源。
- 功能：所有现有用户可见页面保留；允许重组导航和页面层级。
- 弹层：覆盖全部高频业务弹层；低频同类配置使用统一模板，不重复创造视觉语言。
- 本阶段：仅完成设计规格与 HTML 原型；不改 Android 业务代码、资源或布局。

## 2. 设计基准与 Autosize

| 场景 | 设计宽 × 高 | 方向 | 用途 |
| --- | --- | --- | --- |
| TV 常规页面 | 960 × 540 | 横屏 | 首页、点播、直播、详情、设置、文件、历史等 |
| 手机常规页面 | 540 × 960 | 竖屏 | 浏览、搜索、详情、个人中心、设置、文件等 |
| 手机全屏视频/直播 | 960 × 540 | 横屏 | 进入全屏播放器后自动横转 |
| 手机音频 | 540 × 960 | 竖屏优先 | 音频页、迷你播放器、播放队列；可视化全屏时按横屏播放器规则 |

后续实现应让不同界面按对应的 Autosize 设计基准换算：TV 为 `design_width_in_dp=960`、`design_height_in_dp=540`；手机常规页为 540×960；手机全屏播放器在横转后为 960×540。方向切换不能丢失播放进度、当前线路、已打开的设置面板或详情页滚动位置。

## 3. 全局视觉系统

### 3.1 三层壁纸模型

所有页面统一采用三层：

1. 壁纸原图：用户在个性化中随时更换。
2. 场景遮罩：首页约 36%，内容列表约 56%，设置与高密度表单约 78%。
3. 内容表面：卡片、工具栏、列表和弹层使用稳定的深色/浅色表面，保证文字和焦点可读。

播放器不显示普通页面壁纸；使用纯内容画面、黑色渐变遮罩和高对比 OSD。浅色主题时保留同一层级模型：壁纸降低饱和度，内容表面改为暖白，黄色播放色改为深色文字承载。

### 3.2 核心令牌

| 用途 | 深色默认值 | 规则 |
| --- | --- | --- |
| 内容底色 | `#070A10` | 所有深色页面的稳定阅读底色 |
| 玻璃表面 | 白色 10% 叠加遮罩 | 仅用于卡片、工具栏和非关键层 |
| 主强调色 | `#E7FF4D` | 播放、当前焦点、主要确认操作 |
| 高对比文字 | `#F8FAFC` | 标题、主要数值、关键信息 |
| 次要文字 | 蓝灰色 | 描述、时间、未选状态，不承担主操作 |

TV 焦点态必须同时具有亮色填充/轮廓、外扩描边和微光，不依赖单一颜色变化；手机触控态使用明确的点击目标、按下缩放和短暂反馈，不模拟 TV 焦点。

## 4. 信息架构与固定入口

### 4.1 TV 一级导航

左栏常驻八个入口，顺序固定：

1. 首页
2. 搜索
3. 点播
4. 直播
5. 收藏
6. 历史
7. 文件
8. 设置

左栏只承担跨页面跳转。顶部提供当前站点、壁纸快捷入口和时间/设备状态；页面局部操作放在正文区。返回键按“关闭临时层 → 返回上级 → 离开页面”的稳定顺序执行。

### 4.2 手机一级导航

底部固定五个入口：首页、点播、直播、收藏、我的。搜索在首页与点播顶部常驻；“我的”归集历史、观看报告、文件、扫码、推送/投屏和设置。

### 4.3 点播、直播、壁纸、线路的准确位置

| 项目 | 手机 | TV | 补充规则 |
| --- | --- | --- | --- |
| 点播 | 底部“点播” | 左栏“点播” | 进入点播首页、分类、筛选、搜索结果与详情 |
| 直播 | 底部“直播” | 左栏“直播” | 进入频道、分组、节目单、直播详情与直播播放器 |
| 壁纸 | 我的 → 设置与个性化 → 壁纸 | 设置 → 个性化 → 壁纸 | 全应用即时生效，按场景应用不同遮罩 |
| 当前线路 | 详情页“线路”与播放器 OSD“线路” | 详情页“线路”与播放器 OSD“线路” | 仅切换当前内容，保持当前剧集和播放进度 |
| 点播源/直播源 | 我的 → 设置与个性化 → 内容源 | 设置 → 内容源 | 全局管理源站、健康状态与默认线路策略 |

“点播/直播”与“点播源/直播源”必须使用不同名称，避免将内容入口误解为配置入口。

## 5. 页面覆盖与设计模板

### 5.1 发现与内容浏览

| 页面/状态 | 新设计模板 |
| --- | --- |
| 首页 | 继续观看为首屏唯一主动作；下方为推荐横向内容轨；TV 使用左栏+大横幅，手机使用纵向首屏+底栏 |
| 搜索 | 顶部搜索框、搜索建议、历史、热词和结果共用一个连续页面；TV 支持虚拟键盘焦点，手机优先系统输入 |
| 点播/分类 | 分类与筛选共用页面骨架；筛选作为顶部横向条件或手机底部半屏面板 |
| 影视详情 | 封面、主播放、收藏、分享、播放器设置；后续按选集、线路、简介、演员、相关推荐排序 |
| TMDB 详情/人物页/Web 主题详情 | 沿用详情模板，替换对应的资料、作品轨与操作区 |
| 选集/集详情 | TV 为焦点网格或分页列表；手机为横向节选+完整选集底部面板 |

详情页新增并固定“⚙ 播放设置”：TV 位于主播放按钮旁，手机位于播放、收藏、分享同一操作组。点击后不跳离详情页：TV 从右侧展开设置面板，手机弹出底部半屏面板。

### 5.2 播放、直播与音频

| 页面/状态 | 新设计模板 |
| --- | --- |
| 视频播放器 | 全屏 OSD：顶部信息、中央播放/快进、底部进度和控制，右侧/底部为设置面板 |
| 手机全屏视频 | 从竖屏详情自动横转到 960×540；单击显示 OSD，双击快进/后退，长按临时 2× |
| 直播播放器 | 复用视频 OSD，替换为频道、节目单、时移、直播线路和收藏 |
| 音频播放器 | 竖屏封面、播放队列、评论/歌词、定时关闭；迷你播放器跨页面保留 |
| 播放器设置 | 字幕、弹幕、画面、倍速、清晰度/线路；详情页设置与播放器设置共享状态 |

播放器全屏时隐藏普通页面壁纸与导航。设置面板关闭后，TV 焦点返回触发控件；手机关闭后保持 OSD 与进度。

### 5.3 个人媒体与工具

| 页面/状态 | 新设计模板 |
| --- | --- |
| 收藏 | 保持一级入口；支持点播、直播、音频等分组 |
| 历史 | 继续观看、已看完、批量清除三态；可跳回原详情或直接续播 |
| 观看报告 | 统一深色数据卡和时间范围选择，避免与内容浏览页混用视觉层级 |
| 文件/文件夹 | 本地、SMB、下载和网盘共享文件浏览器模板；文件操作放入上下文菜单 |
| 扫码、投屏、推送、接收 | 统一为工具页；设备选择、二维码、成功/失败反馈复用相同面板 |
| 崩溃、空状态、无网络、无结果 | 使用明确的插图/图标、状态说明、一个主操作和可选次操作 |

### 5.4 设置与个性化

TV 设置为左侧分类+右侧内容双栏；手机设置为“我的”内的分组列表。设置分类为：个性化、播放、字幕与弹幕、增强、内容源、数据与同步、关于。

个性化页包含壁纸库、收藏壁纸、自定义图片、主题模式、首页密度与焦点动效。壁纸切换预览后立即应用到全应用。

### 5.5 现有页面映射清单

下表确保现有入口不会在导航重组时遗漏。名称按代码中现有 Activity/Fragment 的职责归类，最终实现可以重命名为面向用户的中文标题，但不能删除能力。

| 页面群 | 现有页面/能力 | 新归属 |
| --- | --- | --- |
| 启动与首页 | Home、首页分类 Fragment、收藏 Fragment、文件夹 Fragment | 首页、点播、收藏、我的/文件 |
| 搜索与点播 | Search、Vod、Type、Filter、Quick Search、Hot Word、Search Record | 搜索与点播内容流 |
| 详情资料 | 影视详情、TMDB Detail、TMDB Person、Web Theme Detail、Episode Detail | 统一影视详情模板与资料子页 |
| 播放 | Video、Player OSD、Control、Quality、Parse、Track、Speed、Subtitle、Danmaku、Timer、Episode List | 横屏全屏播放器及设置面板 |
| 直播 | Live、Channel、Group、EPG、Live Line、Live Program、Live Control | 直播入口、频道详情、节目单和横屏播放器 |
| 音频 | Audio、Audio Source、Audio Comment、Mini Player | 音频页与全局迷你播放器 |
| 媒体库 | Collect、Keep、History、Viewing Report、File、Folder | 收藏、保留/稍后看、历史、报告、文件 |
| 外部协同 | Cast、Push、Scan、Receive、Device、APK Push | 我的 → 工具，TV 可从工具/设置快速进入 |
| 设置 | Setting、Player、Danmaku、Subtitle、Enhance、Personal、Theme、Config、DoH、UA | 设置分类与统一选择型弹层 |
| 维护与异常 | Update、Restore、Pass、Buffer、Crash、Site Health、Ad Rule/Stats、Sync/Remote Trust | 设置/系统维护页与信息、确认、进度模板 |

## 6. 弹层与状态规则

所有高频弹层采用四类模板：

1. 选择列表：线路、清晰度、字幕、音轨、站点、壁纸、设备、倍速。
2. 多级设置：播放器设置、弹幕设置、字幕设置、内容源。
3. 确认操作：删除历史、恢复、退出、更新、危险设置，主次按钮始终分明。
4. 信息与进度：缓冲、下载/扫描、投屏连接、站点健康、更新说明。

TV 弹层在焦点顺序中可预测；手机弹层使用底部半屏或居中对话框。不可关闭的进度态必须说明当前任务和取消/返回能力；错误态必须保留重试和查看详情的路径。

## 7. 交互与可访问性

- TV：所有可操作项必须具有稳定的上下左右焦点关系；焦点不依赖透明度的微小变化。
- 手机：主要触控目标不小于常规可点击尺寸；底部导航不被全屏播放器覆盖。
- 文本：标题、状态、线路和字幕选项在任意壁纸下达到高对比；长标题可两行截断，不遮挡关键操作。
- 动效：焦点放大、页面进入、弹层出现保持短促；“减少动效”偏好关闭非必要缩放和微光。
- 状态继承：选集、线路、字幕、弹幕、倍速、画面设置在详情与播放器间同步；横竖屏切换不丢状态。

## 8. HTML 原型交付要求

最终原型以单独、可离线打开的 HTML 展示，包含：

- TV 960×540 与手机 540×960 两套视图；手机全屏播放器另含 960×540 横屏视图。
- 全页面导航与页面矩阵；点击切换关键页面、播放器 OSD、播放器设置、线路切换和壁纸。
- 真实感中文内容、深色/浅色切换及至少四种壁纸预览。
- 所有布局尺寸、间距、圆角、色彩和交互状态均在原型中标注或可读取，便于 Android XML 一比一还原。

## 9. 验收清单

- 所有现有用户可见 Activity、Fragment、播放器页与高频 Dialog 都能映射到上述模板。
- 点播、直播、壁纸、当前线路、内容源管理均有明确且不冲突的入口。
- 手机浏览页为 540×960，手机视频/直播全屏为 960×540，TV 为 960×540。
- 任意壁纸下首页、列表、设置、对话框和 TV 焦点均清晰可读。
- 详情页和播放器均存在播放器设置入口，并共享已选设置。
- HTML 原型能完整展示双端，不依赖 Android 运行时或网络接口。
