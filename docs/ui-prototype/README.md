# WebHTV 双端 UI 原型

直接双击 `webhtv-dual-ui-prototype.html` 即可离线打开；不需要网络、构建工具或本地服务。所有内容、壁纸和内容源数据均为文件内的本地演示状态，不会读写真实配置。

## 画板与 Autosize

- TV 常规页：960 × 540，`design_width_in_dp=960`、`design_height_in_dp=540`。
- 手机常规页与手机音频：540 × 960，`design_width_in_dp=540`、`design_height_in_dp=960`。
- 手机全屏视频/直播：960 × 540，`design_width_in_dp=960`、`design_height_in_dp=540`。

顶部三个预览按钮可直接切换画板。手机从详情播放视频或进入直播会自动切换横屏；音频保持竖屏。音频最小化后，迷你播放器会跨手机页面保留。

## 关键验收路径

- 详情共享设置：首页内容 → 详情 → “⚙ 播放设置”。面板包含字幕、弹幕、画面、倍速、清晰度和当前线路；打开设置后进入播放器，面板和选择状态保持。
- 内容源：设置 → 内容源 → 点播源或直播源“管理”。可在本地添加、启停、设为默认、移除，并切换默认线路策略；健康状态可见。详情/播放器的“当前线路”仍只作用于当前内容。
- 个性化：TV 顶栏“壁纸”，或设置 → 个性化。深/浅主题与四种壁纸即时生效；卡片、输入框、设置面板和弹层使用主题语义表面。
- 返回层级：`Esc`/返回键依次关闭弹层、播放器设置、内容源管理和播放器，再返回上页。
- TV 焦点：方向键移动本地焦点模型，操作项保留亮色轮廓、外扩描边和微光。
- 手机视频手势：单击切换 OSD，左右双击后退/快进 10 秒，长按显示临时 2×反馈。

## 页面覆盖

“页面覆盖与现有能力映射”面板中的按钮均可到达对应模板或状态，覆盖：

- 首页、搜索、点播分类/筛选、影视详情、TMDB 详情、人物页、Web 主题详情、选集/集详情。
- 视频 OSD、直播频道/分组/EPG/时移、音频封面/队列/评论/定时与迷你播放器。
- 收藏、Keep/稍后看、历史、观看报告、文件/文件夹、扫码、投屏、推送、接收和设备。
- 个性化、播放、字幕与弹幕、增强、内容源、数据与同步、关于、更新、恢复、站点健康、同步/远程信任，以及空/错误/无网络状态。
- 选择列表、多级设置、确认操作、信息/错误、进度和设备选择弹层。

## 自动验收

运行：

```bash
node docs/ui-prototype/offline-smoke-check.mjs
```

该依赖零第三方包的 Node harness 会加载 HTML 的真实内联脚本，调用实际注册的 click、keydown、dblclick 和 pointer handler，并断言真实 `renderApp()` 输出与状态流。它还检查离线范围、三画板 Autosize、共享设置、音频方向、内容源可变状态、语义浅色表面对比和页面映射。浏览器控制台也可运行 `runOfflineAcceptanceCheck()`；两种检查都不做像素级截图验收。
